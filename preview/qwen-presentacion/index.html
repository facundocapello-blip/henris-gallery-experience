La propuesta

Un sistema que respeta la forma de trabajar de una galería.

Henris Gallery nace de un Excel real con 66 columnas. No reemplaza esa lógica: la ordena. Separa lo que estaba mezclado, conecta lo que estaba suelto, calcula lo que se hacía a mano.

i.

Pedidos como eje central

Cada venta es un pedido. A él se atan obras, pagos y cliente. Nada queda flotando.

ii.

Obras separadas de pagos

Un pedido puede tener varias obras y varios pagos. Los pagos pertenecen al pedido, no a una obra.

iii.

Saldo calculado, no copiado

El saldo pendiente se calcula automáticamente. La columna “PAGO PENDIENTE” del Excel queda como referencia, nunca como fuente.

iv.

Trazabilidad del origen

Cada campo conserva su referencia histórica al Excel. Se sabe de dónde vino cada dato.

Mapeo de pedidos

Cada columna del Excel, en su lugar dentro del sistema.

Seleccioná un campo para ver de dónde viene, a dónde va y qué regla aplica. Los ejemplos documentados abajo ilustran el funcionamiento; el mapeo completo se valida caso por caso.

Seleccioná un campo para ver el detalle de la correspondencia.
Maqueta de correspondencias. Ejemplos documentados; mapeo completo sujeto a validación. Los identificadores técnicos (ID de pedido, obra, pago, cliente) son generados por el sistema y no provienen de una columna del Excel.
Circuito de datos

Un pedido, varias obras, varios pagos, un cliente.

El pedido es el eje. Las obras describen qué se vende. Los pagos describen cómo se cobra. El cliente describe a quién. Todo se calcula, nada se duplica.

Clientes

Nombre, contacto y datos comerciales. Un cliente puede tener muchos pedidos a lo largo del tiempo.
